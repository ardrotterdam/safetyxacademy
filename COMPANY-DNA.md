## Brand architecture

SafetyXAcademy has **three** approved brand representations. They are complementary assets, not competing brand names.

| Hierarchy | Form | Role |
|-----------|------|------|
| Official written identity | `SafetyXAcademy` | Plain text, SEO, schema, email, legal, documents |
| Full visual identity | `safetyXacademy` | Preferred full visual wordmark (orange X) |
| Compact visual identity | `SXA` | Official monogram / brand icon |

Brand consistency does **not** mean using exactly the same graphical asset everywhere. Consistency means using the correct approved representation for the context.

No fourth spelling or logo variation should be introduced without explicit approval.

## 2. Primary visual wordmark

The preferred **full visual** wordmark is:

**safetyXacademy**

Visual treatment:

| Part | Colour |
|------|--------|
| `safety` | white / neutral |
| `X` | Safety Orange |
| `academy` | white / neutral |

The **X** is the visual brand anchor. Do not randomly colour other letters orange.

`#FF6600`

Use the existing SafetyX design token if the stylesheet already defines this colour. Do not create a second slightly different orange.

On the existing dark SafetyX interface:

- `safety` = white / existing wordmark neutral
- `X` = Safety Orange
- `academy` = white / existing wordmark neutral

### Where to use

Use `safetyXacademy` where there is enough visual / horizontal space, for example:

- website header
- website footer
- presentations
- large marketing assets
- branded documents
- social banners
- course materials
- larger email headers where appropriate
- future dashboards when space allows

| Form | Role |
|------|------|
| `SafetyXAcademy` | Official written brand name |

## 6. Logo / wordmark usage

Preferred order by context:

1. **Small / square / icon space** → use the official **SXA** monogram asset.
2. **Prominent visual space** → use the official existing full logo / `safetyXacademy` wordmark asset when available.
3. If an HTML/CSS wordmark must be recreated in a spacious context, use the approved `safetyXacademy` visual treatment (only **X** in `#FF6600`).
4. If colour / HTML styling is unavailable, write `SafetyXAcademy`.

Never fake a different logo spelling. Never create another unofficial SafetyXAcademy logo just to fit a section. Do not invent additional abbreviations or logo treatments.
