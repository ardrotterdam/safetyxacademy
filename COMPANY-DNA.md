- forms
- documents
- invoices

- Safety XAcademy

## 2. Visual wordmark

The preferred **visual** wordmark is:

**safetyXacademy**

Visual treatment:

| Part | Colour |
|------|--------|
| `safety` | neutral / white |
| `X` | Safety Orange |
| `academy` | neutral / white |

The **X** is the visual brand anchor.

On the existing dark SafetyX interface:

- `safety` = white / existing wordmark neutral
- `X` = Safety Orange
- `academy` = white / existing wordmark neutral

### Official Safety Orange

`#FF6600`

Use the existing SafetyX design token if the stylesheet already defines this colour. Do not create a second slightly different orange.

### Critical distinction

| Form | Role |
|------|------|
| `safetyXacademy` | Visual wordmark treatment |
| `SafetyXAcademy` | Official written brand name |

Do not confuse these two rules.

## 3. The X

The X is the most recognizable visual element of the brand.

Treat the orange X consistently across:

- website header
- footer when wordmark is shown
- HTML email header
- presentation assets
- social graphics
- marketing assets
- future dashboards
- course materials

Rules:

- Do not randomly make other letters orange.
- Do not use multiple competing accent colours around the wordmark.
- Do not add gradients to the X unless a future formal rebrand explicitly changes this rule.

Preferred order:

1. Use the official existing logo asset when available.
